# Frontend

Aplicación Angular (standalone, Reactive Forms) para gestionar solicitudes de crédito.

Cómo levantarla (`npx ng serve`), ejecutar los tests (`npx ng test --watch=false`) y compilar (`npx ng build`) está explicado en el [README de la raíz](../README.md), secciones "Puesta en marcha manual" y "Tests y calidad".
